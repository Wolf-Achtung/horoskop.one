# Schriften für die Bilderzeugung

Nur für `scripts/make_og_image.py` — die Website selbst lädt ihre Schriften
über Google Fonts, nicht von hier.

| Datei | Schrift | Verwendung im Teilbild |
|---|---|---|
| `IMFellEnglish-Italic.ttf` | IM Fell English Italic | Wortmarke „DIE MONDLESE" |
| `CormorantGaramond-MediumItalic.ttf` | Cormorant Garamond Medium Italic | Zeile „Ein Zug pro Tag …" |

Beide stehen unter der SIL Open Font License 1.1; die Lizenztexte liegen
als `OFL-*.txt` daneben. Bezogen aus den npm-Paketen
`@fontsource/im-fell-english` und `@fontsource/cormorant-garamond`
(WOFF2 → TTF via `fontTools`).
